# 品牌定位

## 核心关系

```text
润木同学 = 个人品牌 / 创作者身份
润木听听 = 第一个 App 产品
亲子英语包播放器 = 产品品类说明
rmrm.me = 官方网站 / 可信落点
```

网站应始终先讲清“润木同学”这个人和长期方向，再自然引出“润木听听”这个产品。

## 长期主线

```text
一个普通人，如何借助 AI，把生活和工作中的真实小需求做成能用的产品。
```

这条主线比“AI 教育品牌”“智能学习平台”“超级个体逆袭”等表达更真实，也更适合当前阶段。

## 润木听听的表达边界

推荐表达：

```text
润木听听是一个给英语一般的爸妈用的亲子英语包播放器。
```

可以强调：

- 爸妈先开口，孩子自然听见。
- 不打卡、不测评、不制造学习压力。
- 像听音乐一样，选择一个生活场景，听几句当下能说出口的话。

避免使用：

- 英语课程。
- 学习平台。
- AI 英语老师。
- 发音评分。
- 训练营。
- 打卡体系。
- 儿童学习报告。

## 语气原则

- 第一人称可以使用，但不要过度自我包装。
- 真实、克制、清楚，比宏大叙事更重要。
- 不虚构用户评价、下载量、媒体报道或商业合作。
- 不把当前项目包装成大公司或教育机构。
