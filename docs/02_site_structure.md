# 网站结构

## 当前页面

`rmrm.me` 当前采用轻量静态站结构：

```text
index.html                         首页

tingting.html                      润木听听产品页
notes.html                         开发笔记列表
notes/why-parent-english-player.html  开发笔记文章页
about.html                         关于润木同学
```

当前不保留站内 `privacy.html` 和 `support.html`。隐私政策由 App 在其他位置调取，反馈表放在 App 内。

## 顶部导航

推荐导航：

```text
首页｜润木听听｜开发笔记｜关于
```

导航要求：

- 所有链接必须真实可访问。
- 不显示“支持”导航。
- 不显示不存在的栏目。
- 手机端需要保持可读、可点击。

## 首页职责

首页是个人品牌主页，主要说明：

1. 润木同学是谁。
2. 正在用 AI 做真实小工具。
3. 当前第一个产品是润木听听。
4. 后续会记录开发过程和产品思考。

首页不应承担完整产品说明，不应重复产品页的大段内容。

## 润木听听产品页职责

产品页负责说明：

- 润木听听是什么。
- 适合哪些爸妈。
- 如何使用。
- 它不是什么。
- 当前内测版能力。
- 下载方式和联系方式。

产品页可以展示网盘链接和邮箱，但不放站内反馈表。

## 开发笔记职责

开发笔记用于发布真实开发记录。当前首篇文章来自根目录：

```text
润木听听开发笔记.md
```

文章页应适合手机阅读，支持清晰标题层级、引用、列表和代码块。暂时不做评论、搜索、标签系统或订阅系统。

## 关于页职责

关于页解释为什么是润木同学在做这些产品，可以简短呈现：

- 非科班背景。
- 土木工程、保险销售、跨境电商等经历如何影响产品判断。
- 为什么开始借助 AI 做个人开发。
- 后续会记录什么。

不要写成简历包装或成功学故事。

## 路由验收

每次修改后检查：

- 首页、产品页、开发笔记列表、文章页、关于页都能打开。
- 所有内部链接没有 404。
- 页面没有 `href="#"`。
- 页面没有“待补充”“链接待替换”等占位文字。
