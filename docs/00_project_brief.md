# 项目简报

## 项目背景

`rmrm.me` 是“润木同学”的个人品牌官网，也是第一个 App 产品“润木听听”的官方落点。

当前网站已经从早期规划阶段进入静态页面实现阶段。它不再只是一组规划文档，而是一个可以本地预览、提交到 GitHub 并部署到静态托管平台的站点。

## 核心定位

```text
润木同学的个人品牌主页 + 润木听听产品入口 + 开发笔记
```

网站要帮助访问者快速理解：

- 润木同学是一个真实的个人创作者。
- 润木听听是一个给爸妈用的亲子英语包播放器。
- 这个项目不包装成课程、学习平台或 AI 教育品牌。
- 后续会记录 AI 辅助个人开发、产品取舍和真实迭代过程。

## 当前服务目标

1. 给用户一个可信落点。

用户从 App、社交平台、朋友转发或 GitHub 看到“润木同学 / 润木听听 / rmrm.me”时，可以打开网站确认项目来源和产品定位。

2. 给润木听听提供产品入口。

产品页讲清楚润木听听适合谁、如何使用、当前能力和下载方式。网盘链接使用真实地址，不显示占位按钮。

3. 给长期运营保留开发记录入口。

开发笔记不是传统博客，也不是营销文章，而是记录一个非科班个人开发者如何借助 AI 把真实需求做成产品。

## 当前边界

网站不维护站内隐私政策页，隐私政策已由 App 在其他位置调取。

网站不提供反馈表，App 内已有反馈入口。

网站公开联系邮箱为：`runmu@rmrm.me`。

## 不做什么

当前版本不做：

- 登录 / 注册。
- 评论 / 社区。
- 支付 / 会员。
- AI 聊天。
- 在线英语包市场。
- 用户上传。
- 数据库。
- 后台管理。
- 虚构用户评价、下载量或媒体报道。

## 成功标准

当前版本完成后，应满足：

1. 首页能在短时间内讲清润木同学是谁。
2. 产品页能讲清润木听听不是课程、不是测评工具。
3. 开发笔记入口真实存在，至少有一篇正式文章。
4. 所有导航、按钮和页脚链接真实可访问。
5. 网站可作为静态项目直接部署。
