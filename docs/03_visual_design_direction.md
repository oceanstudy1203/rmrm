# 视觉设计方向

## 整体气质

`rmrm.me` 应保持清爽、克制、可信，有个人开发者真实感和轻量产品感。

推荐关键词：

```text
干净
温和
真实
留白充足
信息清楚
```

不要做成儿童培训机构、重包装 AI 公司或炫技落地页。

## 色彩

当前视觉可以继续使用温和背景色、深色正文、绿色和木色点缀。

注意避免：

- 大面积蓝紫渐变。
- 霓虹科技风。
- 过度卡通化。
- 单一色系堆叠导致页面沉闷。

## 版式

- 首页突出“润木同学”和长期主线。
- 产品页突出“润木听听”的使用场景和产品边界。
- 开发笔记页以阅读体验为主，正文宽度不要过宽。
- 关于页保持真实、简短、有层次。

## 组件

继续复用现有按钮、卡片、标签、页头和页脚样式。

按钮文字要表达真实动作，例如：

```text
了解润木听听
阅读开发笔记
邮件联系
```

不要使用无目标的按钮或占位按钮。

## 移动端

移动端优先检查：

- 顶部导航是否换行正常。
- 首屏标题和按钮是否拥挤。
- 长标题是否溢出。
- 开发笔记正文是否易读。
- 邮箱和外部链接是否可点击。

## 不新增

- 自动轮播。
- 弹窗订阅。
- AI 机器人插画。
- 虚假数据仪表盘。
- 用户评价墙。
- 复杂动画。
- 站内反馈表。
