# 视觉设计方向

## 1. 设计目标

`rmrm.me` 第一版的视觉目标是：

```text
清爽、可信、有产品感，同时保留一点润木品牌的温度。
```

网站不是儿童培训机构官网，也不是炫技型 AI 官网。它首先是一个个人品牌主页，承接“润木同学”这个真实创作者身份，同时为第一个 App 产品“润木听听”提供正式入口。

视觉设计要让用户感受到：

- 这是一个真实的人在认真做产品。
- 网站信息清楚，不花哨。
- 润木听听是一个轻量、温和、可理解的 App。
- 这个项目有一点技术感，但不是冰冷的 AI 公司风。

第一版不追求惊艳，追求稳、干净、可读、可信。

## 2. 总体风格

已确定方向：

```text
科技清爽为主，少量木色和绿色作为品牌点缀。
```

这意味着网站整体不应走纯儿童风，也不应走浓重蓝紫 AI 风。

推荐关键词：

- 清爽。
- 克制。
- 可信。
- 移动端友好。
- 轻产品感。
- 真实个人开发者。
- 温和但不幼稚。

避免关键词：

- 早教机构。
- 课程销售页。
- 炫酷 AI 平台。
- 重营销落地页。
- 花哨动画站。
- 复杂 SaaS 官网。

## 3. 色彩方向

### 3.1 主背景色

推荐使用：

```text
白色
浅灰白
轻微暖白
```

示例色值：

```text
#FFFFFF
#F8FAF9
#F6F7F4
#FBFAF7
```

背景要干净，保证文字阅读舒适。

不要使用大面积高饱和背景，不要使用复杂渐变背景，不要使用深色科技背景作为第一版主视觉。

### 3.2 主文字色

推荐使用：

```text
近黑
深灰
```

示例色值：

```text
#17201B
#1F2933
#2F3430
#4A514C
```

正文文字不要太浅。网站会有隐私政策和支持说明，必须保证可读性。

### 3.3 品牌强调色

推荐使用偏沉稳的绿色或蓝绿色：

```text
墨绿色
蓝绿色
低饱和青绿色
```

示例色值：

```text
#2E6F5E
#2F7D6D
#3A7D72
#1F6F64
```

用途：

- 主按钮。
- 链接。
- 小标签。
- 当前页状态。
- 重点信息点缀。

不要使用荧光绿或过亮的儿童绿。

### 3.4 品牌点缀色

可以少量使用木色和嫩绿色，呼应“润木”和头像/App 图标。

示例色值：

```text
#B98555
#C79662
#E7C7A0
#8DAA45
#A3B95F
```

用途：

- 小图标点缀。
- 局部背景块。
- 分割线。
- 首页视觉卡片中的轻量装饰。

点缀色只应少量出现，不要让整个网站变成木色/绿色主题站。

### 3.5 禁止方向

第一版避免：

- 大面积紫蓝渐变。
- 大面积黑色科技风。
- 大面积卡通彩虹色。
- 高饱和橙色营销风。
- 复杂光效和发光按钮。
- 大面积木纹背景。

## 4. 字体与排版

### 4.1 字体原则

第一版优先使用系统字体。

推荐 CSS 字体栈：

```css
font-family:
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  "PingFang SC",
  "Microsoft YaHei",
  sans-serif;
```

不要引入复杂 Web Font，避免加载慢和跨平台显示问题。

### 4.2 标题

首页主标题要清楚，但不要过度巨大。

建议：

- 移动端 H1：32px - 40px。
- 桌面端 H1：48px - 64px。
- 行高：1.1 - 1.2。
- 字重：600 - 700。

不要使用负字距。不要用过窄或装饰性字体。

### 4.3 正文

正文建议：

- 移动端：16px - 17px。
- 桌面端：17px - 18px。
- 行高：1.7 左右。
- 每段不要太长。

隐私政策、支持页等长文本页面尤其要注意行宽。

桌面端正文内容宽度建议：

```text
640px - 760px
```

产品介绍页可用更宽布局，但正文段落仍应保持舒适阅读宽度。

### 4.4 信息层级

每个页面要有清晰层级：

```text
页面标题
一句话说明
核心 CTA
内容模块
页脚
```

不要在一个屏幕里塞太多卡片。第一版宁愿留白多一点，也不要显得拥挤。

## 5. 页面版式

### 5.1 总体布局

推荐使用：

```text
顶部导航
主内容
页脚
```

页面最大宽度：

```text
1120px - 1200px
```

内容左右边距：

```text
移动端：20px - 24px
桌面端：32px - 48px
```

### 5.2 首页首屏

首页首屏建议使用左文案、右轻量视觉的结构，但移动端要上下排列。

桌面端：

```text
[ 文案区 ]    [ 产品/头像轻视觉 ]
```

移动端：

```text
[ 文案区 ]
[ 轻视觉 ]
```

文案区优先级高于视觉。用户打开首页，第一眼要先读懂“润木同学在做什么”。

### 5.3 产品页首屏

润木听听产品页可以更聚焦 App：

```text
产品名
品类说明
它不是什么
它怎么帮爸妈开口
```

可以展示 App 图标或简单手机界面截图。第一版如果没有正式截图，可以先只展示 App 图标和文字，不要用假截图。

### 5.4 长文本页面

隐私政策和支持页应采用单栏布局。

推荐：

```text
最大宽度 720px
左对齐
标题清楚
分节明确
列表简洁
```

不要把隐私政策做成花哨落地页。

## 6. 组件风格

### 6.1 按钮

按钮要清楚、克制、易点。

主按钮：

- 背景使用墨绿色或蓝绿色。
- 白色文字。
- 圆角 8px - 12px。
- 移动端高度至少 44px。
- 文案短。

示例文案：

```text
了解润木听听
填写反馈表
查看隐私政策
```

不要使用：

```text
立即逆袭
马上变强
免费领取课程
立即购买
加入会员
```

次按钮：

- 白底。
- 浅边框。
- 深色文字。
- Hover 时轻微背景变化。

### 6.2 卡片

可以使用少量卡片，但不要满屏卡片。

卡片适合：

- 展示润木听听。
- 展示 3 个记录方向。
- 展示适合谁 / 不是什么。
- 展示常见问题。

卡片样式：

- 白底。
- 浅边框。
- 轻微阴影或无阴影。
- 圆角 12px 左右。
- 内边距 20px - 28px。

不要使用厚重阴影、玻璃拟态、发光边框。

### 6.3 标签

标签可以用于表达：

```text
个人开发
AI 编程
第一个 App
亲子英语包播放器
内测准备
```

标签颜色要轻，不要像促销标签。

### 6.4 图标

如果使用图标，建议使用简单线性图标或极简实体图标。

用途：

- 工具。
- 播放。
- 反馈。
- 隐私。
- 记录。

不要堆太多图标，不要做成图标墙。

## 7. App 图标和头像使用原则

### 7.1 润木听听 App 图标

App 图标可以用于：

- `tingting.html` 产品页首屏。
- 首页的“第一个作品”模块。
- 网站 favicon。
- 社交分享图的产品角标。

使用方式：

- 小尺寸。
- 独立展示。
- 配合产品名和品类说明。

不要把 App 图标放成大面积背景。

### 7.2 润木同学头像

润木同学头像可以用于：

- `about.html` 关于页。
- 首页右侧轻视觉。
- 页脚小标识。
- 后续文章作者信息。

使用方式：

- 小尺寸或中等尺寸。
- 不要铺满首屏。
- 不要和 App 图标混在一起造成识别混乱。

### 7.3 两者关系

头像代表“润木同学”。

App 图标代表“润木听听”。

网站需要让用户理解这两个东西的关系：

```text
润木同学制作了润木听听。
```

不要让用户误以为头像就是 App 图标，或者 App 图标就是个人头像。

## 8. 移动端优先

### 8.1 为什么移动端优先

内测用户和社交平台用户大概率从手机打开网站。

应用市场审核人员也可能从移动设备查看隐私政策或支持页。

因此第一版必须先保证手机体验。

### 8.2 移动端要求

移动端必须满足：

- 首屏标题不换得很碎。
- 正文不溢出。
- 按钮高度足够。
- 链接容易点击。
- 顶部导航不拥挤。
- 图片不压住文字。
- 页面横向不滚动。
- 页脚链接清楚。

### 8.3 移动端导航

第一版页面少，可以避免复杂菜单。

推荐：

```text
顶部左侧：润木同学
顶部右侧：润木听听 / 支持
```

或移动端将导航换成两行。

如果使用汉堡菜单，也必须非常简单，不要引入复杂 JS。

## 9. 动效原则

第一版不需要复杂动画。

允许：

- 按钮 hover 轻微变化。
- 链接 hover 颜色变化。
- 卡片 hover 轻微上浮。
- 页面加载无动画或非常轻的淡入。

不建议：

- 大面积滚动动画。
- 视差滚动。
- 粒子背景。
- 光效追踪。
- 复杂 SVG 动画。
- 自动播放视频背景。

网站当前目标是可信和清楚，不是展示动画能力。

## 10. 图片和素材原则

第一版可以使用：

- App 图标。
- 润木同学头像。
- 简单产品截图。
- 简洁抽象图形。

不建议使用：

- 夸张儿童插画。
- 模糊 stock photo。
- 和产品无关的家庭照片。
- AI 味很重的科技背景图。
- 大面积木纹。

如果没有合适素材，宁可用纯文字和简单卡片，不要强行堆图。

## 11. 文案视觉配合

网站文案和视觉要保持一致。

例如：

```text
我在用 AI 做一些自己真的会用的小工具。
```

这句话适合清爽、留白、个人感，不适合配一个超大科技机器人背景。

又例如：

```text
给英语一般的爸妈用的亲子英语包播放器。
```

这句话适合温和、清楚的产品卡片，不适合配“冲刺高分”“学习排名”一类视觉。

视觉不要和产品定位打架。

## 12. 可访问性和可读性

第一版至少要做到：

- 文字和背景对比度足够。
- 按钮可见。
- 链接有明确状态。
- 图片有 `alt` 文案。
- 页面标题清楚。
- 长文本分节。
- 手机端不需要放大才能读。

隐私政策页尤其要保证可读性。不要把法律/政策文字做得很小。

## 13. 后续扩展方向

如果第一版上线后需要扩展，可以逐步增加：

- 开发记录页面。
- 作品集页面。
- App 截图区域。
- 内测招募页。
- 常见问题页。
- 简单文章列表。

但这些都不是第一版必须。

第一版视觉系统要留出扩展空间，但不要提前做复杂组件库。

## 14. 设计验收标准

后续开发网页时，可以按以下标准验收视觉：

1. 打开首页 5 秒内，能知道这是“润木同学”的个人主页。

2. 用户能看到“润木听听”和“亲子英语包播放器”的关系。

3. 页面不像儿童培训机构，也不像重包装 AI 公司。

4. 手机端阅读舒适，没有文字溢出。

5. 按钮和链接清楚可点。

6. App 图标和头像使用克制，不喧宾夺主。

7. 没有复杂动画和沉重视觉负担。

8. 隐私政策和支持页保持严肃清楚。

## 15. 一句话结论

`rmrm.me` 的视觉方向是：

```text
清爽科技感打底，
用木色和绿色保留润木的温度，
用克制的产品感建立信任。
```

第一版要像一个认真个人开发者的可信主页，不要像培训机构，也不要像炫技 AI 官网。
