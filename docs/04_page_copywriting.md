# 页面文案基准

## 文案来源

首页正式文案来源：

```text
rmrm-homepage-copy.md
```

首篇开发笔记来源：

```text
润木听听开发笔记.md
```

实现页面时可以根据版式做轻微拆分，但不要改变核心意思，也不要添加虚构用户数据、评价、媒体报道或下载量。

## 开发笔记

栏目名称使用：

```text
开发笔记
```

不要使用“博客”“洞察”“思想”等过重名称。

当前首篇文章标题：

```text
我为什么做一个给爸妈用的英语播放器
```

## 关于页

关于页应真实说明背景和动机，不写成创业融资介绍、成功学故事或技术专家包装。

## 禁止出现

生产页面和文档示例中都应避免：

- `href="#"`
- `链接待替换`
- `待补充`
- 虚构用户评价
- 虚构下载量
- 虚构媒体报道
- 未确认的内测入口
