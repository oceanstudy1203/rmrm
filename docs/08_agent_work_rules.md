# Agent 工作规则

## 工作原则

后续修改 `rmrm.me` 时，请先阅读：

```text
README.md
rmrm-homepage-copy.md
rmrm-website-structure-codex-spec.md
docs/
```

再阅读要修改的页面文件。不要凭空重写整个项目。

## 当前项目事实

- 项目是纯静态 HTML/CSS。
- 没有构建工具。
- 没有数据库。
- 没有登录、支付、评论、社区或后台。
- 当前页面为首页、润木听听、开发笔记、文章页、关于页。
- 网站不维护站内隐私政策页。
- 网站不维护站内反馈表。
- 公开联系邮箱为 `runmu@rmrm.me`。

## 修改规则

1. 优先复用现有视觉和结构。
2. 每次只改和任务相关的文件。
3. 不新增无真实目标的按钮。
4. 不使用 `href="#"` 作为正式链接。
5. 不在页面显示“待补充”“链接待替换”。
6. 不虚构用户评价、下载量、媒体报道或合作方。
7. 不把润木听听包装成课程、学习平台或 AI 老师。
8. 不新增站内反馈表。
9. 不恢复 `privacy.html` 或 `support.html`，除非用户明确要求。

## 文案规则

首页以 `rmrm-homepage-copy.md` 为基准。

开发笔记文章以根目录 Markdown 为来源：

```text
润木听听开发笔记.md
```

产品页使用真实下载链接：

```text
https://pan.baidu.com/s/54fekx11pCHH0ssUu3yIpbg
```

## 验证规则

修改完成后至少检查：

- 所有内部链接有效。
- 每页只有一个 `h1`。
- 页面 SEO 基础信息存在。
- 本地静态服务器能返回主要页面。
- `git diff --check` 通过。

本地预览命令：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

## 汇报规则

完成后按任务范围汇报：

1. 修改了哪些文件。
2. 做了哪些结构或文案更新。
3. 是否新增或删除路由。
4. 验证命令和结果。
5. 是否还有需要用户提供的资料。
