# 隐私、反馈与联系方式边界

> 文件名沿用历史命名。当前网站已经不维护站内隐私政策页和支持反馈页。

## 当前决策

- 网站删除 `privacy.html`。
- 网站删除 `support.html`。
- 隐私政策由 App 在其他位置调取。
- 反馈表在 App 内已有入口。
- 网站只保留公开联系邮箱：`runmu@rmrm.me`。

## 网站可以展示什么

网站可以展示：

```text
邮件联系：runmu@rmrm.me
```

产品页可以说明当前为内测产品，并引导用户通过 App 内反馈入口或邮件联系。

## 网站不要展示什么

不要在网站中展示：

- 反馈表。
- 飞书表单占位链接。
- `support.html` 入口。
- `privacy.html` 入口。
- 孩子姓名、照片、学校、地址等敏感信息收集提示。
- 任何飞书 API token、机器人 token 或应用密钥。

## 隐私事实边界

虽然网站不再维护隐私政策页，润木听听的公开表述仍应保持克制：

- 不说自己会收集实际没有收集的数据。
- 不暗示有登录、账号、云同步或 AI 测评能力。
- 不提前承诺未上线的付费、音色服务、云端功能。

如果 App 后续新增匿名统计、云同步、付费、用户自定义内容或第三方服务，需要同步更新 App 内隐私政策来源和项目文档。

## 联系邮箱

当前公开邮箱：

```text
runmu@rmrm.me
```

除非用户明确更换，不要使用其他邮箱。
